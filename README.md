DockPanel Suite
===============

DockPanel Suite Lite - The Visual Studio inspired docking library for .NET WinForms

A fork of DockPanel Suite. This is an attempt at optimization and slight reworking for my personal projects.

For more details, check out [http://dockpanelsuite.com](http://dockpanelsuite.com).
Visual Studio 2019 Community edition and above is recommended to compile the code base.

Supports NET Framework 4.8
